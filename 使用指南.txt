班级积分管理系统 · 使用指南
============================================================
（本包为通用纯净版：不含任何班级的名单或姓名，收到后请按第 2 节录入自己的班级）


一、这个包里有什么
------------------------------------------------------------
  班级积分系统.html   系统本体。双击即用，不需要安装，不需要联网。
  班级助手.exe        桌面助手（可选）。提供悬浮球、全屏呼出、开机自启动、
                      每日明细自动落盘、局域网同步。
  使用指南.txt        本文件。

  建议把这三个文件放在同一个文件夹里（助手要靠"同目录"来找界面文件）。


二、三步开始
------------------------------------------------------------
  第 1 步  双击「班级积分系统.html」——用 Edge 或 Chrome 打开
           （系统里只要装了 Edge 就能用，Windows 10/11 都自带）
  第 2 步  进入右上角「⚙️ 设置」，先把【班级名单】改成你自己班的学生
  第 3 步  保存后即可开始记分

  想要悬浮球和全屏呼出，就再双击一次「班级助手.exe」，屏幕角落会出现一个小球。


三、录入自己的班级名单（纯净版是空的，必须做这一步）
------------------------------------------------------------
  在「⚙️ 设置」里有两个名单框，都是 JSON 格式，点一下就能编辑：

  1) 班级名单（学生总名单）
     格式：{"姓名": {"岗位": "", "职务": "", "寝室": ""}}
     最省事的写法：只写姓名即可，例如
        {"张三": {}, "李四": {}, "王五": {}}
     分数、岗位、寝室都可以留空，系统会自动补齐。

  2) 小组 / 寝室 名单
     格式：{"组名": ["姓名1", "姓名2"]}
     不想手打 JSON，就用这两个功能：
       · 👆 点选模式（推荐，触屏友好）
         点一个组 → 下面列出全班学生 → 点学生加入，再点一下移出 → 点「✅ 应用小组」
       · 直接用文本框改 JSON（高级模式），改完同样点「✅ 应用小组」
     注意：每次改完都要点「应用」才生效；应用时会保留每个人的分数。

  3) 点名名单
     在随机点名页里可以「导入名单」，支持 txt 文件（自动识别 UTF-8 与 GBK 编码），
     一行一个姓名即可。名单为空时会用班级名单自动生成。


四、日常使用
------------------------------------------------------------
  · 登记积分
      左上角选择对象类型（个人 / 小组 / 寝室）→ 选组 → 点学生 → 选事项标签
      或填自定义分数与原因 → 点「提交登记」。
      触屏上：学生直接显示为按钮，点一下即选中；自定义分数旁有 −5 / −1 / +1 / +5
      步进按钮，不用调出键盘。
  · 快捷加分
      在排行榜上长按某一行约半秒，会弹出「给某人 +1 分？」的确认框，确认即可。
      （短按不会有任何动作，不会误触。）
  · 撤销
      登记后可以在记录区撤销最近一笔。
  · 口令锁
      默认没有启用密码。需要防止学生乱改时，可在设置里开启口令锁
      （只锁写操作，不影响查看）。


五、桌面助手（悬浮球）
------------------------------------------------------------
  · 单击小球      呼出 / 收起界面。收起时是最小化，任务栏上随时能点回来。
  · 长按小球      展开菜单，可选「管理系统 / 随机点名」并直接跳转
  · 开机自启动    设置里可以打开 / 关闭，随系统启动自动驻留
  · 快捷键        Ctrl+Alt+D（可在启动参数里改）
  · 退出          长按展开菜单 → 退出

  助手与界面必须放在同一个文件夹：助手会找同目录下的「班级积分系统.html」。
  如果找不到，它会弹窗告诉你当前目录，把 html 放进去即可。


六、每日明细（自动存到同目录文件夹）
------------------------------------------------------------
  助手运行时会自动在它所在目录建一个「每日明细」文件夹：

     每日明细\2026-09-22.csv    用 Excel 直接打开（UTF-8，中文不乱码）
                             列：时间 / 类型 / 对象 / 分值 / 原因
     每日明细\2026-09-22.md     可读小结：逐条明细 + 当日个人变化 + 全班总分快照

  · 每次记分后 1 秒内自动更新当天文件；跨天会自动开新文件
  · 同一天反复写是覆盖更新，不会产生一堆重复文件
  · 设置面板里有「💾 立即写入今日明细」与「📂 打开明细目录」两个按钮
  · 助手没运行时这个功能自动关闭，记分不受任何影响


七、随机点名
------------------------------------------------------------
  在顶部切到「🎲 随机点名」页：
  · 点「开始点名」（或直接轻点大转盘区域）开始滚动，再点一次提前结束
  · 空格键 / 回车键同样可以开始与停止
  · 抽取是公平随机的，并会自动避免同一个人连续被点到
  · 下方显示本轮已点到的名单，可随时清空重来
  · 名单可以在本页导入 / 编辑，不会影响积分数据


八、数据存在哪里 / 怎么备份
------------------------------------------------------------
  · 所有数据保存在浏览器本地存储里，不联网、不上传
  · 设置面板可「导出 JSON」备份、「导入 JSON」恢复
  · 换电脑、换浏览器：先导出，再到新机器导入
  · 清理浏览器数据 / 用无痕窗口会导致数据丢失，请定期导出备份
  · 建议每学期导出一次存档


九、局域网同步（可选，两台设备互相传分）
------------------------------------------------------------
  · 前提：两台设备连在同一个局域网（同一个 Wi-Fi 或同一台交换机）
  · 两台都双击运行一次助手，各自会自动判断谁是服务器、谁是客户端
  · 设置面板「🌐 局域网同步」里能看到：本机角色、连上的服务器地址、
    待同步条数、发现了几台设备；也可以点「立即同步」
  · 断网时照常记分，恢复联网后自动补传
  · 名单改动以最后修改的为准（两边不会互相覆盖分数）

  ⚠️ 学校网络提醒：不少校园网做了设备隔离或禁止广播，这种情况下
     两台设备互相发现不了。判断方法：在一台的设置里看能否显示对方；
     或在一台上打开浏览器访问 http://对方的IP:17892/net?k=class-local-2026
     能返回内容就说明通，什么也打不开就是被网络隔离了 ——
     这种网络下同步无法使用，请改用「导出 / 导入」搬运数据。


十、常见问题
------------------------------------------------------------
  Q：打开是一片空白 / 顶部出现红色警告条？
  A：多半是浏览器太旧，或有三个典型原因（页面顶部会直接写出来）：
     用 Edge / Chrome 打开；文件还在压缩包里就先解压；从微信/QQ 里直接点开的
     请先「另存为」到桌面再打开。

  Q：点了悬浮球没反应，或打开的界面是旧版本？
  A：说明同一台机器上有不止一份助手在跑。请在任务管理器里结束所有
     「班级助手.exe」，只保留你新放的那一份，再重新双击它。

  Q：助手提示找不到界面文件？
  A：把「班级积分系统.html」和「班级助手.exe」放进同一个文件夹再启动。

  Q：不想要开机自启动了？
  A：设置面板里关掉即可（它会恢复成你开启之前的状态）。

  Q：第一次启动时 Windows 弹窗问是否允许网络访问？
  A：点「允许访问」，否则局域网同步用不了（单机记分不受影响）。

  Q：Excel 打开 CSV 是乱码？
  A：本系统的 CSV 是 UTF-8 带 BOM，Excel 2016 及以上直接双击即可。
     若仍乱码，用「数据 → 从文本/CSV」导入并选择 UTF-8。


十一、给多位老师共用
------------------------------------------------------------
  · 每个班一个文件夹，各放一份 html 与助手即可，互不干扰
  · 想让两台设备（比如教室一体机 + 办公电脑）共用一份数据，用局域网同步，
    或定期导出/导入 JSON
  · 助手可以只装在一体机上，办公电脑直接用浏览器打开 html 也行
